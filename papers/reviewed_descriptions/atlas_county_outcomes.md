# atlas_county_outcomes

This dataset contains 3,219 rows and 64 columns. Each row represents a county, identified by state and county 2010 FIPS codes. Outcomes are stored in separate columns by race and gender for children born in 1978–1983 whose parents were at the 25th percentile of the national income distribution. Household income ranks use children's mean earnings in 2014–2015, including own and spouse's income. Incarceration measures indicate residence in a correctional facility on April 1, 2010. Associated standard errors incorporate sampling error and privacy noise added to estimates. The supplied folder calls this Table 4, while its codebook calls it Table 2.

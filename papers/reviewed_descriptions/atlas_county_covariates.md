# atlas_county_covariates

This dataset contains 3,221 rows and 35 columns. Each row represents a county, identified by state and county 2010 FIPS codes. The table contains neighborhood characteristics from public sources, including household income, poverty, educational attainment, racial shares, employment, population density, rents and job growth. County covariates are generally population-weighted averages of tract-level measures; annual job growth, job density and population density are exceptions. Variable-specific suffixes indicate different measurement periods, so this is not a single-year table. Annual job growth covers 2004–2013; the two-bedroom median gross rent measure uses the 2011–2015 ACS. The supplied folder calls this Table 12, while its codebook calls it Table 10.
